# Ejekanonu Benjamin Chukwudum — Portfolio

A responsive, single-page portfolio for a data analyst and data scientist based in Jos, Nigeria. The site uses semantic HTML and custom CSS; no build tools or package installation are required.

## Project files

- `index.html` — the complete page, including its styles.
- `Ejekanonu Benjamin.jpg` — the portrait displayed in the hero section.

Keep the image beside `index.html`, or update the image `src` in the HTML if you move or rename it.

## Preview locally

Open `index.html` in a browser. Alternatively, run a simple local server from the project folder:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## Personalize before publishing

- Replace the example GitHub, LinkedIn, and Medium URLs and `hello@example.com` with your own profiles and email.
- Replace the three sample project cards and their GitHub links with your real work.
- Fill in the bracketed personal-interest prompts in the About section.
- Google Fonts are loaded from the web; system sans-serif fonts provide a fallback.

## Deploy

This is a static site and can be hosted without a build step:

- **GitHub Pages:** push the files to a repository, then enable Pages for the branch and folder containing `index.html`.
- **Vercel:** import the repository and deploy it as a static site from the project root.
